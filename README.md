# Snake-Water-Gun-Game
🐍 Snake Water Gun Game in C

A simple command-line game written in C where you play against the computer.

🎮 How to Play
s → Snake 🐍
w → Water 💧
g → Gun 🔫
🧠 Rules
Snake drinks Water → Snake wins
Water drowns Gun → Water wins
Gun kills Snake → Gun
✨ Features
Random computer choice
Simple and clean logic
Beginner-friendly C project
